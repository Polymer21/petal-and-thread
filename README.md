# Petal & Thread Studio

Static landing page for the floral shop. Plain HTML, CSS, and a little vanilla JavaScript. No build step.

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 4173
```

## GitHub Pages

The site is ready to publish from the repository root (`index.html`, `styles.css`, `script.js`, `assets/`). A `.nojekyll` file is included so GitHub Pages serves every asset as-is.

Pages is not turned on in this repo. To publish later: repository **Settings → Pages → Build and deployment**, choose the branch, and set the folder to **/ (root)**.
